# Steak & Fogo
 
Projeto **Steak & Fogo** – uma aplicação web desenvolvida para gerenciar produtos, cardápio e atendimento de uma churrascaria/steakhouse online.  
O objetivo é oferecer uma experiência simples, rápida e responsiva para clientes e administradores.
 
---
 
## Tecnologias Utilizadas
 
- **Frontend:** HTML5, CSS3, JavaScript  
- **Backend:** Node.js / PHP   
- **Banco de Dados:** MySQL
- **Estilização:** Bootstrap / CSS puro  
- **Controle de Versão:** Git & GitHub
